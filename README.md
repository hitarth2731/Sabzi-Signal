# 🍅🧅 Sabzi Signal

**When and where do tomato and onion wholesale prices spike in India, and can rainfall give procurement teams an early warning?**

## Status

🚧 In progress: Day 1 (project setup)

## Business problem

Tomato and onion prices swing sharply, hurting farmers, consumers and grocery businesses.
This project builds a data pipeline and dashboard to detect price spikes and test whether rainfall is an early signal.

## Stakeholder

Procurement Head at a grocery / quick-commerce company

## Data sources

- Mandi prices: data.gov.in Open Government Data API (Agmarknet)
- Weather: Open-Meteo Historical Weather API (CC BY 4.0)

## Tools

Python (API extraction) · Google BigQuery / SQL (cleaning, modelling, analysis) · Python (EDA) · Power BI (dashboard) · Excel (metric dictionary, reporting)
